# Contributing to Conclawd

Thank you for your interest in Conclawd!

## How to Contribute

This project accepts **issues only** -- pull requests are **not reviewed or merged**. The source is published for transparency; development happens solo, so please do not open PRs.

You can help by:

- **Reporting bugs** -- unexpected behavior, crashes, UI glitches
- **Requesting features** -- ideas for new functionality or improvements
- **Sharing use cases** -- how you use Conclawd and what would make it better

## Modifying Conclawd

If you want to change or extend Conclawd, **fork the repository**. The [MIT License](LICENSE) allows you to modify and redistribute your own version freely -- no permission needed.

## Reporting Issues

Please use [GitHub Issues](https://github.com/btopia1128/conclawd-ide/issues) and include:

- macOS version
- Steps to reproduce the problem
- Expected vs actual behavior
- Screenshots or screen recordings for UI issues

## Building from Source

If you want to run Conclawd locally:

```bash
git clone https://github.com/btopia1128/conclawd-ide.git
cd conclawd-ide
xcodegen generate
open Conclawd.xcodeproj
```

See [README.md](README.md) for full setup instructions including ML model downloads.
